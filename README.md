# Bliss Metrics Plumbing of Hialeah

A responsive plumbing services website built with React, TypeScript, and Vite.

## Run locally

**Prerequisite:** Node.js 20.19+ or 22.12+.

```sh
npm install
npm run dev
```

## Build and deploy

Create a production build with:

```sh
npm run build
```

Upload the generated `dist` directory to any static web host. The build uses relative asset paths, so it works from a domain root or a subdirectory. If you add client-side routes later, configure the host to serve `index.html` for those routes.
